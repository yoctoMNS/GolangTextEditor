# フェーズ2 実装計画

このドキュメントはフェーズ2（基本テキストエディタ機能の拡充）の進捗管理用。
`CLAUDE.md` 8章「過剰設計の禁止」の方針は引き続き有効で、ここに無い機能
（マルチタブ、シンタックスハイライト、プラグイン機構、ゲームエンジン統合など）
は依然としてフェーズ2の対象外。

## 進め方のルール

1. **1コミット = 1つの、外から見て確認できる振る舞いの変更のみ。**
   「〇〇機能一式」をまとめて1コミットにしない。
2. **コアロジック（`internal/buffer`, `internal/editor`）とUI配線
   （`internal/app`）は必ず別コミットに分ける。** コア側は必ずテスト付きで
   先に単独コミットする（既存のアーキテクチャ方針＝外側→内側の一方向依存
   に合わせる）。
3. **1コミットの目安は「新しいテストケースが数個〜10個程度で説明しきれる
   範囲」。** それを超えそうならさらに分割する。
4. **各ステップに着手する前に、この計画のどのステップ番号を実装するかを
   お互い確認してから着手する。** 勝手に複数ステップをまとめて実装しない。
5. 完了したステップはこのファイルの該当行を `[ ]` → `[x]` に変更し、
   コミットハッシュを追記する。

## 保留中の判断事項

- **ステップ10（コピー）：** Goでクリップボードを扱う標準ライブラリが無いため、
  外部依存を1つ追加する必要がある。着手時に候補ライブラリを提示して相談する
  （`CLAUDE.md` 4章のルール通り、軽量なものを優先して選定する）。
